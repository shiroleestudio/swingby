# 내린 단계

2026-10 사용자 피드백("해법이 같은 단계가 세 개씩 반복된다")으로 장마다 8단계 → 5단계로 줄였다.
같은 장에서 놓인 천체와 정답 발사 각도가 비슷한 단계를 여기로 내렸다. 지우지 않은 이유:

- 이미 깬 기록(저장 키가 단계 ID)과 도감 출처가 이 ID 를 가리킬 수 있다
- 나중에 다른 장에 다시 쓰거나 비교용으로 본다

`npm run register` 는 `src/levels/data/` 만 훑으므로 여기 있는 단계는 게임에 나오지 않는다.
다시 올리려면 `data/` 로 옮기고 register → messier → validate 순서를 밟는다.
